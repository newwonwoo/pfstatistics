# QA — 사업지구(수용·환지) 특례 · 지구면적 (2026-09-28)

> 요구 : 「택지유형을 넣으면 면적을 봐야 한다 — 수용/환지/지구단위계획을 가져올 API 가 있는지」 ·
> 「지구 면적에 따라 심사 평가가 달라진다」 · 「주소 검색하는 그리드에서」 ·
> 「면적 데이터가 있으면 바로 표출, 없으면 사용자가 직접 입력」

## 1. 규정
교통환경(5) · 주거편의(5) 단서 — 수용(또는 사용)·환지 방식으로 개발·조성되는 사업지구는 지구면적별로 등급 하한을 둔다.

| 지구면적 | 최저 등급 |
|---|---|
| 500만㎡ 이상 | 매우양호 (5점) |
| 100만㎡ 이상 | 양호 이상 (4점) |
| 50만㎡ 이상 | 보통 이상 (3점) |
| 50만㎡ 미만 | 열악 이상 (2점) |

반경 안 시설로 낸 등급이 이보다 낮으면 올리고, 높으면 그대로 둔다. 평균점수는 그대로 적는다(검산용).

## 2. 원천 조사 — 찾은 것과 실제로 되는 것

| 원천 | 주는 것 | 판정 |

## 3. 설계
- **주소 바로 아래 「사업지구」 줄** — 주소가 확정되면 `/api/district` 가 좌표로 세 원천을 부른다.
  질문 「이 사업지가 수용·환지 방식 사업지구 안에 있습니까?」 · 칩 : [아니오 — 사업지구 밖] · 예 — [원천이 찾은 지구 · 면적] · [목록에 없음 · 직접 입력]. 면적은 칩을 누르면 바로 차고 고칠 수 있다.
- **미리 고르는 규칙** — 이름이 수용 법을 말하거나(택지개발·공공주택·도시개발…) 공공 시행자가 등록한 사업지구 → 그것.
  사업지구경계·토지이용계획 모두 비면 → 사업지구 밖. 토지이용계획만 사업지구(도시개발구역 등)라 하면 고르지 않고 면적을 직접 받는다.
- 값은 `manual['사업지구']` — 보관·엑셀·점수가 이미 그 길로 흐른다. 사업지를 초기화하면 같이 지운다.
- 요약 줄 · 교통환경/주거편의 시트 머리 · 엑셀 머리 · 평균점수 근거 · 심사평점표 관문이 같은 값을 말한다.

## 4-2. 인근아파트 초기분양률 「지구 내 최초 분양 = 4점」 (2026-09-28)
사용자 확정 「최초 아니다/맞다를 선택하면 되겠네」 — 원천이 「최초 분양」 을 말하지 못하므로(청약홈 2020-02~) 사람이 답한다.
- ① 사업지구 안인가 = 주소 아래 질문 · ② 그 지구의 최초 분양인가 = 초기분양률 칸 「수용·환지 지구」 줄(처음엔 「특례」 라 적었다 — 아래 4-3) [아니오 — 조사합니다] / [예 — 최초 분양 (4점)]
- **둘 다 예일 때만** 4점. 사업지구 밖이면 질문 대신 「해당하지 않습니다」. 판정은 `manual.js` `nearbySpecial` 한 곳
- 사업지구 안인데 안 고르면 심사평점표 관문에 한 줄
- 자가진단 4건(지구 안·최초 / 지구 안·최초 아님 / 지구 밖·최초라 답함 / 적용 아파트 없음) — 구간표 91/91

## 4-3. 「특례」 라는 말을 뺐다 · 비교단지 택지유형 (2026-09-29)
사용자 질문 「특례? 그게 규정에 나오는 워딩인가」 — **아니다.** 2026-09-16 가이드북 요약 때 내가 붙인 이름이다.
확인된 원문은 초기분양률의 「*」 각주 한 줄뿐이고 거기에도 「특례」 는 없다.
| 자리 | 전 | 후 |
|---|---|---|
| 평균점수 근거(화면·엑셀) | 사업지구 특례 : 부천상동 … | 수용·환지 사업지구 지구면적 : 부천상동 … |
| 초기분양률 칸 줄 이름 | 특례 | 수용·환지 지구 |
| 최초 분양 안내 | 최초 분양 특례(4점)가 적용되어 … | 사업지구 내 최초 분양이라 4점(열악)입니다 … |
| 직접 입력 옆 | 특례가 적용되어 있습니다 | 사업지구 내 최초 분양이라 조사값을 쓰지 않습니다 |
| 심사평점표 관문 사유 | 「특례」 줄 | 초기예상분양률 탭 … 「수용·환지 지구」 줄 |

**비교단지 택지유형** — 청약홈 APT 공고의 Y/N 표시(공공주택지구 · 대규모 택지개발지구 · 수도권 내 민영 공공주택지구)가
하나라도 Y 면 「공공택지」. 전부 N 이면 **미상**(민간으로 단정하지 않는다). 본건 택지유형은 채우지 않는다(사용자 지시) —
주소 아래에서 고른 사업지구를 본건 제원 밑에 참고로만 적는다. 비교사업장·인근 초기분양률 표에 「청약홈 : …」 줄, 엑셀에 「택지 (청약홈 표시)」 열.

## 5. 남은 것
- **교통환경·주거편의 특례 단서 원문을 아직 못 받았다** — 적용 조건(공공택지인지 · 수용·환지 사업지구인지 · 시기)을 원문으로 확인해야 한다.
- **개발방식은 추정이다** — 실무자가 확정한다.
- **지구단위계획구역은 후보에서 뺐다**(사용자 지적 「지구단위계획은 분양단지랑 같은게 아냐」). 면적 검산에는 여전히 쓴다(동탄2·검단 고시면적 대조).
- 택지정보시스템 CSV(면적·법령·택지구분)는 해외 망에서 막혀 쓰지 못했다. 배포 서버(서울)에서 되는지는 확인하지 않았다.
- 택지유형(라.) 칩과 자동 연결은 하지 않았다 — 시행자(공공/민간)가 힌트로 보인다.

## 6. 결론
요구사항에 **적합**하다. 면적이 원천에 있으면 칩 한 번으로 차고, 없으면 그 자리에서 넣는다.
특례가 점수 → 평균점수 근거 → 엑셀까지 같은 값으로 흐르는 것을 배포본에서 확인했다.
