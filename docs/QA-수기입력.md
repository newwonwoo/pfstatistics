# 품질확인서 — 수기입력 (A 산출)

- 대상 : 규모 및 배치(5) · 평형구성(5) · 인근아파트 초기 분양률(10) 구간표
- 커밋 : `1135f03`
- 검증자 : 자가검증 (구간 경계 전수 + A 합산 경로 검증)

## 1. 무엇이 바뀌었나

전에는 **A(분양가격지수 제외 항목 점수)를 내부망 평가표에서 손으로 옮겨 적게** 했다.
그런데 A 안의 항목 대부분을 이 앱이 이미 알고 있었고, 나머지도 구간표만 있으면 값에서 점수가 난다.

| 구분 | 항목 | 배점 |
|---|---|---|
| **자동** (원천 수집) | 교통환경 · 주거편의 · 교육환경 · 브랜드경쟁력 · 주택담보대출금리 | 각 5 |
| **값 → 점수** (새 폼) | 규모 및 배치 · 평형구성 · 인근아파트 초기 분양률 | 5 · 5 · 10 |
| **점수 직접** (구간표 미수령) | 지역미분양 · 지역수요 · 지역경쟁력 · 소비심리지수 | ? · ? · ? · 15 |

## 2. 구간 경계 전수

**규모 및 배치** — `(총세대수×0.5) + (용적률×0.25) + (건폐율×0.25)` → 등급 → 대표점수
```
1050세대 / 190% / 16%  → 가중평균 5    · 매우양호 · 5점
1050세대 / 190% / 59%  → 가중평균 4    · 양호    · 4점
 400세대 / 230% / 25%  → 가중평균 3    · 보통    · 3점
 120세대 / 500% / 60%  → 가중평균 1    · 매우열악 · 1점
```
평균값이 곧 점수가 아니라 **등급의 대표점수**를 쓴다 — 교통환경·주거편의와 같은 규칙이다.
한 칸이라도 비면 점수를 내지 않고 무엇이 비었는지 적는다.

**평형구성** — 작을수록 좋다
```
60㎡ 이하 100세대만          → 1.73  · 매우양호 · 5점
60~85㎡ 100세대만            → 3.41  · 열악    · 2점
85㎡ 초과 100세대만          → 6.66  · 매우열악 · 1점
60㎡ 500 + 60~85㎡ 500       → 2.57  · 양호    · 4점
60~85㎡ 900 + 85㎡초과 100   → 3.735 · 열악    · 2점
```

**인근아파트 초기 분양률**
```
95% → 10점    90% → 10점    85% → 8점    80% → 8점
75% →  6점    70% →  6점    65% → 4점    60% → 4점
59% →  2점     0% →  2점
[수용·환지 지구내 최초 분양사업] → 4점
[적용 아파트 미존재]            → 2점
```

## 3. 평형구성 산식의 ×100 — 빼고 적용했다

원문: `[Σ(평형별 세대수 × 평형별 가중치) / 총 세대수] × 100`
급간: `1.81 미만 / 1.81~3.37 / 3.37~3.41 / 3.41~3.78 / 3.78 이상`

가중치가 **1.73 ~ 6.66** 이므로 가중평균도 그 범위다. ×100 을 하면 **173 ~ 666** 이 되어
어느 급간에도 걸리지 않는다. 급간 네 개(1.81 / 3.37 / 3.41 / 3.78)가 가중치 범위 안에
정확히 들어오는 것이 결정적이다 → **×100 없이** 적용했다.

추정이 아니라 산술적으로 배제되는 쪽을 택한 것이지만, 원문과 다르게 적용한 것이므로
**화면에 원문 산식과 함께 그 사실을 적어** 실무자가 확인할 수 있게 했다.

## 4. A 합산 — 한 곳에서만 만든다

전에는 A 를 **비교사업장 탭의 입력칸**에서 받았다. 이제 수기입력 탭이 단일 지점이고,
비교사업장 탭의 칸은 **읽기전용**으로 바뀌어 그 값을 그대로 보여준다.
두 곳에서 받으면 한쪽만 고쳐져 분양가경쟁력과 초기예상분양률이 조용히 갈린다.

검증 (표본 입력):
```
교통환경 3 · 주거편의 5 · 교육환경 4 · 브랜드경쟁력 4 · 주택담보대출금리 3   [자동]
규모및배치 5 · 평형구성 4 · 인근초기분양률 8                              [값→점수]
지역미분양 8 · 지역수요 5 · 지역경쟁력 6 · 소비심리 12                     [점수 직접]
── 합계 A = 67
```
교통환경 3점은 골든 `(1+4)/2 = 2.5 → 보통 → 3점` 과 같은 경로로 나온 값이다.

**한 항목이라도 비면 A 를 확정하지 않는다.**
```
평형구성을 비우면 → A = null   (부분 합계 63 은 표시하되 A 로 쓰지 않는다)
```
부분 합계를 A 로 쓰면 종합평가 점수가 낮아지고 분양률이 한 급간 떨어진다.

**직접 입력 우선** — 내부망 평가표 값을 그대로 쓰고 싶을 때를 위해 `A 직접 입력` 칸을 뒀다.
넣으면 그 값이 쓰이고, 화면에 "직접 입력" 임을 표시한다.
```
직접 입력 56 → A = 56 · source=override
```

## 5. 절차

단계가 하나 늘었다.
```
자료수집  →  수기입력  →  분양률 산정  →  심사평점
```
수기입력이 끝나야(A 가 확정돼야) 분양률이 나오고, 분양률이 나와야 평점이 나온다.
단계 완료 판정도 그대로 따라간다.

## 6. 결론

요구사항에 **적합**하다. 구간 경계 19개를 전수 확인했고, A 합산의 세 경로
(전 항목 입력 / 일부 미입력 / 직접 입력)를 모두 검증했다.
추정으로 채운 구간은 없다 — 평형구성의 ×100 만 산술적 근거로 빼고 적용했으며 화면에 명시했다.
