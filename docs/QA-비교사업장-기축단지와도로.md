## 4. 한계 (추정으로 채우지 않음)

- **실거래가는 분양가가 아니다.** 이미 팔린 값이고 원천이 **공급면적을 주지 않는다**(전용만).
  심사기준은 공급면적이므로 그대로 비교하면 안 되고, 비교사업장 평균에도 넣지 않는다.
- 카카오 장소검색은 **한 번에 45곳**까지만 준다. 반경 안 아파트 분류 330곳 중 가까운 곳부터 받는다.
- K-apt 는 **관리비 의무단지(준공)** 만 있다 — 소규모·미준공은 세대수·시공사가 빈다.
- 지도 타일 자체는 1배다. 3배로 찍어도 **타일 그림**은 확대의 한계가 있다 —
  선명해지는 것은 캔버스에 직접 그리는 핀·라벨·반경원·경계선이다.
- **구간표 미수령 2개(지역미분양·지역수요)는 그대로 빗금이다.** 원문을 못 받았고 추정하지 않는다.
