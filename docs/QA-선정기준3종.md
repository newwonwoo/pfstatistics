## 2. 화면 — 배포본을 사람처럼 조작 (인천 미추홀구 도화동 731 · 대우건설)

### 비교사업장 (A · C)
- 반경 1km 수집 → 본건 제원 아파트 / 500~999세대 / 50위 이내(대우건설 5위에서 자동)

  두산위브 더센트럴 도화(1년 이내 · 2개 일치)만 선택, 서희스타힐스 더 도화(준공)는 비선택 — Q8 대로
- 규정 머리줄 : 「… 유사도 2개 이상(3개 이상 우선) · 공공분양/10년경과 제외 · **적정분양가는 5년 이내 분양개시 추가 우선**」

### C 경로 — 반경 3km 에서 수동 선택
- 두산위브 더센트럴 도화(분양개시 1.0년) + 주안파크자이 더 플래티넘(6.2년) 체크
- **분양가경쟁력(A)** : 2곳 평균 5,350,863 원/㎡ → 분양가격지수 108.39
- **적정분양가(C)** : ① 평균가격 5,631,134 원/㎡ · 1곳 —
  「분양보증 기준(5년 이내 분양개시 우선)으로 **주안파크자이 더 플래티넘 제외**」 (주황 글씨)
- 두 평균이 **각자의 기준으로 따로** 나오는 것을 확인

### 초기예상분양률 탭 — 인근아파트 초기분양률 (B)
- 규정문 : 「① 거리 **1km** 이내 (2km · 수도권·광역시 1km) · ② 1년 이내 분양 개시 → 없으면 분양 진행 중 (준공 단지는 쓰지 않음) · ③ 주택유형이 일치」
- 반경 칩이 없고 규정 거리로 고정
- 본건 제원 줄이 비교사업장 탭 값과 **같게** 나온다 : 아파트 / 500~999세대 / 50위 이내
- 깔때기 : 반경 1km 안 5건 › 주택유형 일치(아파트) 2건 › 1년 이내 분양개시 1건 › 분양 진행중 0건 (준공 1건은 대상 아님)
- [규정대로 선정] → 두산위브 더센트럴 도화 1곳 · 「2개 일치 · 최다」
- 초기분양률 칸을 비워 두면 「1곳 중 1곳이 비어 있습니다 — 다 채워야 평균을 냅니다」
- 이 탭에서 택지유형을 「민간택지」 로 바꾸면 **비교사업장 탭 본건 제원도 민간택지**로 바뀐다
