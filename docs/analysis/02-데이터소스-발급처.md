## B. 키 발급 필요 — 무료·즉시

### 1. KOSIS 국가통계포털
- **발급**: https://kosis.kr/openapi/
- **경로**: 회원가입 → 오픈API → 활용신청 → 즉시발급
- **환경변수**: `KOSIS_API_KEY`
- **담당 지표**: 주민등록세대수 · 주택보급률 · 부동산시장 소비심리지수
- 캡쳐 11의 화면에 `OPENAPI` 버튼이 있어 해당 통계표는 API 직결이 확인된다

### 2. 한국은행 ECOS — **선택사항이 됨**
- **발급**: https://ecos.bok.or.kr/api/#/AuthKeyApply
- **환경변수**: `ECOS_API_KEY`
- CD(91일)은 금투협 직결로 해결됐다(위 A). ECOS 는 **과거일자 시계열 백필**이 필요할 때만 쓴다.
- **확인된 코드**: `721Y001 / 2010000` = CD(91일) ← 실호출로 검증
- 샘플키(`sample`)는 메타데이터만 되고 실데이터는 안 나온다

> **주택담보대출금리는 수집 대상에서 제외했다.**
> 캡쳐 09 의 4.69% 는 별도 원천이 아니라 CD금리에서 파생되는 값이다(실무 확인).
> 수집기는 CD(91일)만 가져오면 된다.

### 3. 카카오 디벨로퍼스
- **발급**: https://developers.kakao.com/console/app
- **경로**: 앱 생성 → 앱 키 → **REST API 키** 복사 → 플랫폼에 서버 도메인 등록
- **환경변수**: `KAKAO_REST_KEY`
- **담당**: 교통환경 · 주거편의 · 교육환경 (반경내 시설검색 + 지도 캡쳐)
- **문서**: https://developers.kakao.com/docs/latest/ko/local/dev-guide
- 무료 쿼터 일 100,000건 — 심사 건수 대비 충분

### 4. 공공데이터포털
- **발급**: https://www.data.go.kr/
- **경로**: 회원가입 → 데이터셋 → 활용신청 → 승인(자동 즉시 ~ 1일)
- **환경변수**: `DATA_GO_KR_KEY`
- **용도**: 아래 C 항목들
