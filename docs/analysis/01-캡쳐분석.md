```
                     +
              증빙(원천화면 캡쳐 + 출처문구)
```

### 캡쳐 04 — 지역미분양 (계산 시트)
```
지역 미분양비율 = (미분양주택수 / 주민등록세대수) × 100
                = (93 / 178,187) × 100 = 0.05%
평가기준: 0.1% 미만 → 15점 → 매우양호
```
- 증빙 2장 구성: ① 미분양주택수(캡쳐03) ② 주민등록세대수(KOSIS)
- KOSIS 화면: 수록기간 1992~2026.07, **자료갱신일 2026-08-05**, 48)광주시 2026.07 = **178,187**
- 출처: KOSIS 국가통계포털 주민등록세대수 (26.7 기준)
- 📌 배점 15점 = **단일 항목 최대 배점** → 심사 가중치가 큰 핵심 지표

## 4. 확인이 필요한 사항 (피드백 요청)

1. **반올림 규칙** — 교통환경 평균 2.5 → 3점 표기. 올림/반올림/절상 중 무엇인가
2. **거리 판정 기준** — 사업지 경계 기준인가 중심점 기준인가 (교육환경 500m 판정 이슈)
