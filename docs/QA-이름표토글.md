## 1. 요구사항

「지도에 이름표 끄기 버튼이 안 먹는다」(사용자 지적).
원래 요구는 CLAUDE.md 에 있던 것 — **화면에서 끄면 캡쳐도 같이 꺼질 것.
증빙이 화면과 달라지면 안 된다.**

## 2. 분석 (재현)

배포본을 브라우저로 직접 조작해 재현했다.

| 단계 | 화면 이름표 수 |
|---|---|
| 켠 상태 | 22 |
| [이름표 끄기] 클릭 | **22** (그대로) |

버튼 라벨은 「이름표」로 바뀌었다 — **상태는 바뀌는데 지도가 안 따라왔다.**

원인 : `labels` 가 **캡쳐 등록 effect 의 의존성에만** 들어 있고 지도를 그리는 effect 에는 없었다.
그래서 **캡쳐는 꺼지고 화면은 안 꺼졌다** — 요구사항이 거꾸로 나 있던 셈이다.

지도타입 버튼(일반·위성+라벨·위성)은 onClick 에서 `setMapTypeId` 를 지도에 직접 부르므로
영향이 없었다. 죽은 버튼은 이름표 하나였다.

## 3. 설계·개발

지도를 다시 그려 고치는 방법은 **쓰지 않았다** — 타일을 다시 받고 실무자가 맞춰 둔
확대·이동이 초기화된다.

- 라벨 `CustomOverlay` 를 `labelOverlays` ref 에 담아두고 `setMap(map | null)` 로 켜고 끈다
- 그릴 때는 `labelsOnRef` 로 현재 상태를 읽어 **끈 채로 지도가 다시 그려져도 안 켜진다**

## 4. 검증 (실측 · 눈으로 확인)

### 화면
| 단계 | 이름표 수 | 눈으로 본 것 |
|---|---|---|
| 켠 상태 | 22 | 흰 이름표가 지도를 덮음 |
| 끈 상태 | **0** | 이름표 전부 사라짐 · **번호 핀은 그대로** |
| 다시 켬 | 22 | 복구 |

끈 화면의 **타일·확대·위치가 켠 화면과 동일** — 지도를 다시 그리지 않았다는 증거다.
이름표에 가려 있던 카카오 상호(동구초등학교·구지초등학교·인창고등학교)가 드러난다.
이 버튼을 만든 이유가 그것이다.
