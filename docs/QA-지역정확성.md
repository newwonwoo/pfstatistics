## 2. 찾아낸 결함

### 2-1. 인천을 조회해도 경기 값이 나왔다 (가장 심각)

주택보급률·소비심리지수는 KOSIS 지역코드가 통계표 전용이라
config 에 **경기 코드가 고정**돼 있었다. 지역과 무관하게 경기 값이 나왔고,
골든 대조가 지역을 안 봐서 **"검증" 배지까지 달렸다.**

`objL1=ALL` 로 전 시도 코드를 실측해 `objL1BySido` 로 교체.

| 지표 | 경기 | 인천 |
|---|---|---|
| 주택보급률 | 99.4 | **99.0** |
| 소비심리지수 | 125.1 | **114.0** |

### 2-2. 시도만 남고 시군구가 사라졌다

시도만 고르고 지번을 치면 `region` 이 "인천광역시" 로 남았다.
미분양·세대수·매매지수는 전부 시군구 단위라 셋이 통째로 실패 — 사용자가 본 화면이 그것이다.
확정된 좌표의 지번주소에서 시군구를 되짚어 채우고, 그래도 비면 수집을 막는다.

### 2-3. 행정구역이 바뀌어 있었다

`data/regions.json` 이 202506 기준이었다. 202607 로 재생성.

- **인천**: 중구·동구·서구 → 영종구·제물포구·서해구·검단구 등
  ("검단구가 검색 안 된다"는 목록이 낡아서였다. 원천에는 202607부터 있다)
- **전라남도 + 광주광역시 통합**
  통계누리 "전남광주" · KB "광주(코드 12)" · 카카오 "전남광주통합특별시"(정식, 실측)
  KOSIS 두 통계표는 아직 광주/전남을 따로 집계 → 시군구로 가른다

### 2-4. KB 지역코드가 낡아 강원·전북이 조용히 0건

특별자치도 전환 때 강원 42→51, 전북 45→52 로 바뀐 것을 반영하지 못하고 있었다.
KB 목록을 직접 받아 전부 맞췄다.

### 2-5. 시도 단위 지표에 시군구를 떼고 넘김

`region.split(' ')[0]` — 통합 시도는 시군구가 있어야 가린다. 전체 지역을 넘기도록 수정.

### 2-6. 증빙 표가 평가표와 다른 값을 강조

시계열 증빙이 항상 마지막 달을 강조했다(평가표 0.17%(202607) vs 증빙 강조 0.341(202608)).
지표가 채택한 달을 강조하도록 수정.

## 5. 화면

- **수집 기준을 수집 직전에 묻는다.** 옵션으로 두니 아무도 안 건드려 판정이 늘 중심점 기준이 됐다.
  경계 기준을 고르면 지도가 그리기 모드로 열리고, 3점 미만이면 다음으로 못 간다.
- **시설을 지도에 전부 찍는다.** 핀 번호 = 표의 #. 최근접만 찍히던 것을 고쳤다.
  라벨은 겹치니 자리잡기(핀·다른 라벨 회피)로 놓고, 자리가 없으면 라벨만 포기한다.
  브라우저 실측: 6개 시설 → 핀 6개 전부 표시, 라벨 5개 배치, 1개 생략.
- **시트는 시설마다 [표 → 지도] 한 덩어리.** 목록 5건 제한 해제.
- 수집 버튼은 단계 줄에 하나만. 지도 안의 중복 버튼 제거.
