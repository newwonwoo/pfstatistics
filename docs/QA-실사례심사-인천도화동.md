```

⇒ ① 분양가격지수 제외 항목 점수(A) = 59
⇒ ② 분양가경쟁력 = 3   (분양가격지수 143.42 · 매우열악)
```

## 이 회차 기능의 실측

| 확인할 것 | 실측 | 판정 |
|---|---|---|
| 인구유입요인을 표에서 바로 고르기 | 지역수요 시트 표에서 [1개] → 「요인 1개 존재 3점」 · 평균 4 → 4점. 수기입력 A 표의 같은 칩도 1개로 켜져 있음 | 적합 |
| 평형별 세대수 ≤ 총세대수 | 「총세대수 900 · 입력 900 · 남은 0세대」. 넘기면 `scoreUnitMix` 가 점수를 내지 않음(단위검증: 800+800 vs 1,500 → 「100세대 넘습니다」) | 적합 |
| 오피스텔 0.5세대 환산 | 아파트 1,000 + 오피스텔 200 · 총세대수 1,100 → 통과 / 오피스텔 300 → 「50세대 초과」 | 적합 |
| 차선 입력이 적용한 도로 바로 밑 | 인천대로 적용 직후 같은 자리에서 [6] 클릭 → 「인천대로 (왕복 6차선) 124m → 4점」 | 적합 |
| 인근 단지 선정(규정) | 깔때기 **반경 2km 안 16건 › 아파트 11건 › 1년 이내 분양개시 0건 › 분양 진행중 1건**, 「준공 10건은 초기분양률이 없어 제외」 | 적합 |
| 인근 단지 지도 | 후보 핀 번호 = 표의 # · 반경원·경계와 같은 그림 | 적합 |
| 평균분양률 | 1곳 88% → 「80~90% 미만 · 양호 · 8점」. 고른 곳 중 빈 칸이 있으면 평균을 내지 않음 | 적합 |
| 심사평점표가 결과만 보여주는가 | 표 안 입력칸 **0개**. 빈 항목은 「미입력 + [수기입력 탭에서 넣기 →]」 | 적합 |

| 탭 완료 표시 | 자료수집 9● · 수기입력 7(남은 칸) → 다 넣으면 숫자 사라짐 · 심사평점표 ● | 적합 |
| 「다음 →」 배지 | 화면 전체에서 **사라짐** | 적합 |
| [↑ 맨 위로] | 표 하단에서 **13px** 아래, 폭 191px, 심사등급·요율을 같이 적음 | 적합 |
| 엑셀 내보내기 | 851KB · **13시트**(수집요약 · 비교사업장 · 초기예상분양률 · 수기입력 · 심사평점표 · 시설 3 · 통계 5) · 이미지 8장 | 적합 |

## 겪은 것 (앱 문제가 아니라 점검 스크립트 문제)

- **「통계 수집」 을 안 누르고 A 표가 비었다고 읽을 뻔했다.** 스크립트에서 그 단계를 빠뜨렸는데
  화면은 「[통계 수집] 을 누르세요 — 시공능력평가순위가 필요합니다」 라고 정확히 말하고 있었다.
  요약 줄에 「통계 N/7」 이 없고 [엑셀 다운로드] 버튼도 없는 것이 그 증거였다 — **화면이 맞고 내가 틀렸다.**
- **엑셀 다운로드가 안 된다고 볼 뻔했다.** Playwright 가 `window.confirm` 을 기본으로 **거절**한다 —
  빈 탭 확인창에서 취소된 것이다. `page.on('dialog', d => d.accept())` 를 달면 정상 내려온다.
