## 3. 경계값 전수 점검

**브랜드경쟁력** — 구간 경계에서 등급이 밀리지 않는지
```
  1위 → 5점 매우양호      10위 → 5점 매우양호      11위 → 4점 양호
 20위 → 4점 양호          21위 → 3점 보통          50위 → 3점 보통
 51위 → 2점 열악         100위 → 2점 열악         101위 → 1점 매우열악
529위 → 1점 매우열악   ← 동명 업체((주)제일건설) 오매칭 시의 값
```

**주택담보대출금리** — 가산 후 구간에 대보는지
```
CD 1.90% → 3.47% → 5점 매우양호      CD 2.00% → 3.57% → 4점 양호
CD 2.63% → 4.20% → 3점 보통          CD 3.12% → 4.69% → 3점 보통   ← 골든
CD 3.23% → 4.80% → 2점 열악          CD 4.03% → 5.60% → 1점 매우열악
```
구간 경계(4.20 / 4.80 / 5.60)가 **이상** 쪽에 붙는다 — 원문이 "4.2%~4.8%미만" 이므로 맞다.

**지하철역** — 거리 경계
```
  80m → 5점 매우양호    100m → 5점 매우양호    101m → 4점 양호
 300m → 4점 양호        500m → 3점 보통        999m → 2점 열악
1000m → 2점 열악       1001m → 1점 매우열악    부재 → 1점 매우열악
```
"100m**이내**" 이므로 100m 는 5점, 101m 부터 4점. 1000m 까지 2점.

**공원·문화·공공** — pending 해제 확인
```
3개 존재 → 3점 (사업지 반경 1km이내 2개 존재)   ← 전에는 PENDING 이었다
2개 존재 → 3점
1개 존재 → 2점
0개 존재 → 1점
```
3개여도 3점이다. 원문 표에 "3개 모두 존재" 행이 없기 때문이며, 이는 누락이 아니라 표의 끝이다.

**평균 → 등급 → 평가점수**
```
5   → 매우양호 → 5점      4.5 → 매우양호 → 5점      4   → 양호 → 4점
3.5 → 양호    → 4점      3   → 보통    → 3점      2.5 → 보통 → 3점
2   → 열악    → 2점      1.5 → 열악    → 2점      1   → 매우열악 → 1점
```
"4점초과~5점이하" 이므로 4.0 은 양호, 4.5 는 매우양호. 원문 그대로다.

**평가점수는 평균값이 아니다.** 처음에 평균(2.5)을 그대로 점수 칸에 넣었는데,
골든 캡쳐 01 을 대조하니 평가표는 `평균점수 2.5 · 보통` 옆에 **평가점수 3점**을 적는다.
평균은 등급을 고르는 데 쓰고, 평가표에 올라가는 점수는 **그 등급의 대표점수**다.
평균을 그대로 쓰면 총점 합산이 소수로 어긋난다. 화면·엑셀 모두 정정했다.

**주거편의 평균 산출**
```
상업·의료 7점 (1km 내 모두 존재) + 문화·공공·공원 3점 (1km 내 2개 존재)
→ (7+3)/2 = 5.0 → 매우양호
```
7점 행이 왜 있는지가 여기서 설명된다 — 평균을 내면 5점 척도 안에 들어온다.

## 4. 안전장치

- **평균은 전 항목이 판정돼야 낸다.** 한 항목이라도 pending 이면 평균을 내지 않고 사유를 적는다.
  빠진 항목을 0 으로 치면 "아직 모르는 점수" 가 "아주 나쁜 점수" 로 둔갑한다.
- **수기 미입력이 섞이면 표시한다.** 6차선 도로를 아직 안 고른 상태의 기본점수 1점이 평균에 들어가면
  평균 행 아래에 "6차선 왕복도로 미입력 상태의 기본점수가 섞여 있습니다" 를 적는다.
- **추정해서 채우지 않은 것** — 지역경쟁력 매매지수 증감률 상위 구간, 소비심리지수 구간표.
  캡쳐가 잘려 하위 몇 행만 보인다. 소비심리는 골든(125.1 → 110-130미만 → 12점 양호) 한 칸만 아는 상태라
  구간표로 넣지 않았다.
