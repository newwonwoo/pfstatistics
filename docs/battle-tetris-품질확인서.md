# 품질확인서 — 배틀 테트리스

- 대상: `public/battle-tetris/index.html` (단일 HTML 파일, 외부 의존성 없음)
- 원본: Meta AI 공유 아티팩트 `11c10a99-…` (1인용 모바일 테트리스, React)
- 요청: "박진감 넘치는 전투 테트리스로 바꿔줘"
- 작성일: 2026-09-24

## 1. 분석 (원본)

| 항목 | 원본 상태 |
|---|---|
| 모드 | 1인용 점수 게임 |
| 기능 | 홀드, 고스트, 하드/소프트 드랍, 일시정지, 터치 패드 |
| 연출 | 줄 수별 단계 연출 (한 줄! 뾰로로롱 / 두 줄! 콰광 / 세 줄! 빵 / 꽈과과광) |
| 사운드 | 외부 mp3 BGM 스트리밍 + 효과음, 햅틱 |
| 한계 | 상대가 없음 → 긴장감·목표 부족 |

## 2. 설계 (전투화 포인트)

| 요구 | 설계 |
|---|---|
| 전투 | CPU 상대와 1:1 대전, 3판 2선승, 라운드 카운트다운(3·2·1·FIGHT!), K.O. 연출 |
| 공격 | 2줄→1, 3줄→2, 테트리스→4, T스핀 2배, 콤보 보너스, Back-to-Back +1, 올클리어 +10 |
| 방어 | 받을 쓰레기 줄은 빨간 게이지로 표시, 줄을 지우면 먼저 상쇄 |
| 박진감 | 공격 투사체 비행, 피격 흔들림, 화면 플래시, 파티클, 속도 15초마다 상승(BGM 템포 상승), 100초 이후 서든데스(바닥 상승량 30초마다 증가), 위기 시 붉은 경고 + 심장박동음 |
| CPU | 보드 평가 AI, 4단계 난이도(쉬움/보통/어려움/지옥), 상위 난이도는 우물을 비워 테트리스를 노림 |
| 조작 | 키보드(DAS/ARR), 터치 패드, 보드 제스처(드래그 이동·탭 회전·아래로 튕기면 하드드랍·위로 튕기면 홀드) |
| 사운드 | 외부 mp3 의존 제거, WebAudio로 효과음·BGM 합성 (차단·404 위험 없음) |
| 원본 계승 | 줄 수별 한글 콜아웃, 햅틱, 홀드·고스트, 모바일 우선 레이아웃 |

## 4. 검증 중 발견 → 조치

| 발견 | 조치 |
|---|---|
| CPU끼리 붙으면 라운드가 끝나지 않음 (서든데스 약함) | 서든데스 6초 간격, 30초마다 상승 줄 수 증가 → 라운드 약 2분 |
| 어려움 CPU 테트리스 0회 (잔줄만 지워 단조로움) | 우물 전략 추가 → 어려움 14회, 지옥 26회 |
| 360px 폰에서 회전 버튼이 잘림 | 좁은 화면용 패드 크기 추가 |
| 모바일 상단에서 "CPU · 어려움" 줄바꿈 | 모바일은 "CPU"만 표시, 난이도는 상대 보드 위에 표시 |

## 5. 요구사항 적합성 판정

| 요구사항 | 판정 |
|---|---|
| 원본 게임 기반 유지 | 적합 (조작·연출·한글 콜아웃 계승) |
| 전투 테트리스로 전환 | 적합 (CPU 대전, 공격/방어, 라운드제) |
| 박진감 | 적합 (투사체·흔들림·플래시·속도 상승·서든데스·위기 경고) |
| 모바일 동작 | 적합 (터치 패드 + 제스처, 360px 대응) |

**종합: 적합.** 소리와 진동은 브라우저 정책상 헤드리스 환경에서 들을 수 없어, 코드 경로 오류가 없는 것까지만 확인함. 실제 기기에서 청각 확인 권장.
