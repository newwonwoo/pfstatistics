## 1. 분석 (원본)

## 2. 설계 (전투화 포인트)

| 요구 | 설계 |
|---|---|
| 전투 | CPU 상대와 1:1 대전, 3판 2선승, 라운드 카운트다운(3·2·1·FIGHT!), K.O. 연출 |
| 공격 | 2줄→1, 3줄→2, 테트리스→4, T스핀 2배, 콤보 보너스, Back-to-Back +1, 올클리어 +10 |
| 방어 | 받을 쓰레기 줄은 빨간 게이지로 표시, 줄을 지우면 먼저 상쇄 |
| 박진감 | 공격 투사체 비행, 피격 흔들림, 화면 플래시, 파티클, 속도 15초마다 상승(BGM 템포 상승), 100초 이후 서든데스(바닥 상승량 30초마다 증가), 위기 시 붉은 경고 + 심장박동음 |
| CPU | 보드 평가 AI, 4단계 난이도(쉬움/보통/어려움/지옥), 상위 난이도는 우물을 비워 테트리스를 노림 |
| 조작 | 키보드(DAS/ARR), 터치 패드, 보드 제스처(드래그 이동·탭 회전·아래로 튕기면 하드드랍·위로 튕기면 홀드) |
| 사운드 | 외부 mp3 의존 제거, WebAudio로 효과음·BGM 합성 (차단·404 위험 없음) |
| 원본 계승 | 줄 수별 한글 콜아웃, 햅틱, 홀드·고스트, 모바일 우선 레이아웃 |
