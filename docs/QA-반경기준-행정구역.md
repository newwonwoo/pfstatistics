## 2. 경계 기준 반경

판정은 경계 최단거리인데 그림은 대표지번 중심의 원이었다. **실측 차이**:
1km 기준 버퍼의 중심거리가 1100~1181m — 중심원이 모든 방향으로 100~181m 작았다.
원 밖 시설이 "반경 내"로 잡혀도 증빙으로 설명할 수 없는 상태였다.

`geo.bufferPolygon()` 은 판정에 쓰는 `distanceToPolygon` 을 그대로 역산한다
(중심에서 각 방향 이분탐색, 180방향 × 24회). 그린 선이 곧 판정선이다.

| 검증 | 결과 |
|---|---|
| 버퍼 점의 경계거리 (R=500/1000/1500) | min=max=정확히 R (편차 0.00m) |
| 브라우저 합성 캡쳐 (가로로 긴 사업지) | 원이 아닌 스타디움 형태로 정확히 렌더 |
| 지도/캡쳐 일치 | 화면 Polygon 과 캔버스 path 가 같은 ring 사용 |

## 3. 행정구역 선택

`data/regions.json` — 통계누리 미분양(formId 2082)에서 생성. 전국 **228 시군구 + 세종 / 17 시도**.
울릉군·옹진군·군위군 포함. 키 불필요이며 **미분양 수집기와 표기가 같다.**

브라우저 실측(Chromium):

| 입력 | 결과 |
|---|---|
| `금천` (시도=경기도 상태) | `서울특별시 금천구` — 시도까지 자동 전환 |
| `고성군` | `강원특별자치도 고성군`, `경상남도 고성군` **둘 다** |
| `서울 금천` | `서울특별시 금천구` |

## 6. 남는 것

- 차선 수 **자동** 판정. 로드뷰 육안 판정까지만 되어 있다.
  직접적인 답은 도로명주소 전자지도 도로구간(SHP)의 차로수 속성(data.go.kr/data/15050413).
  도시계획시설(도로) 폭원은 중앙분리대·보도를 포함해 차선 수를 단정할 수 없다 — 보조 근거.
- 확정 이후 화면(잠금·시트별 완료표시)은 카카오 키가 배포 환경에만 있어
  샌드박스에서 끝까지 못 돌려봤다. 배포본에서 확인이 필요하다.
