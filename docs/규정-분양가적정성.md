## 0. 가장 큰 발견 — 심사는 **공급면적** 기준이다

평가표의 산식을 그대로 검산했다.

```
가중평균 ㎡당 분양가 = Σ(공급세대수 × 세대당분양가) ÷ Σ(공급세대수 × 공급면적)

본건(탄벌A지구)   388,234,677,655 ÷ 64,171.02 = 6,050,000 원/㎡ = 평당 20,000,000
  84A 419세대 · 전용 84.99 · 공급 111.89 · 세대당 676,933,895
  84B 153세대 · 전용 84.97 · 공급 113.00 · 세대당 683,656,050
```

전용면적으로 나누면 같은 단지가 **약 30% 높게** 나온다(676,933,895 ÷ 84.99 = 7,964,159).
처음 만든 비교사업장 탭은 전용면적 기준이었다 — **틀린 기준이었다.**

→ 기본을 **공급면적(심사기준)** 으로 바꾸고 전용면적도 고를 수 있게 남겼다.
→ 어느 기준을 썼는지 화면·엑셀에 **항상 같이 적는다.**

> 평당 환산은 `400/121` 로 한다. `3.305785` 로 반올림하면 6,050,000원/㎡ 이
> 평당 19,999,999 로 떨어져 평가표(20,000,000)와 1원 어긋난다.

## 1. 인근 유사사업장 요건 (3개)

### ① 거리

| 규정 | 구현 |
|---|---|
| 단위사업장으로부터 **2km(수도권·광역시는 1km) 이내** | 반경 칩의 **규정 기본값을 지역으로 자동 결정**. 서울·인천·경기·6대 광역시·세종 → 1km, 그 밖 → 2km. 화면에 "규정 기본 1km" 로 표기 |
| 비고1 — 해당 사업장이 없으면 **매 1km 범위로 확장** | 반경 칩을 **1·2·3·4·5km** 로 넓혔다. 0건이면 "규정상 매 1km 확장해 재조사합니다" 안내 |
| 비고1 — 5km 이내에도 없으면 10년 이상 경과 사업장 산입 여부 **본·지사 협의** | 자동 판단하지 않는다. 10년 경과 단지는 표에 **"10년 경과 — 제외 권고"** 배지로 표시만 하고 제외 여부는 실무자가 정한다 |
| **Q6/A6 — 거리는 「단위 사업장(단지) 경계로부터 인근 사업장 경계까지」** | 본건 쪽은 **경계 최단거리**로 이미 잰다(사업지 폴리곤). **상대 단지의 경계는 공개 원천에 없다** — 대표지번 1점으로 잰다. 그만큼 거리가 **길게** 잡히므로 이 사실을 표 아래에 명시했다. 숨기면 나중에 왜 틀렸는지 못 찾는다 |

### ② 시기

| 규정 | 구현 |
|---|---|
| 심사 시점 기준 **최근 1년 이내 분양 개시**한 사업장 | 청약홈 `CNTRCT_CNCLS_BGNDE` 로 판정 |
| **Q7/A7 — "분양 개시일"은 관례상 「공급계약시작일」** | 모집공고일(`RCRIT_PBLANC_DE`)이 아니라 **공급계약시작일**을 쓴다. 표의 열 이름도 「분양개시일」 로 바꿨다 |
| 해당 사업장이 없으면 **분양 진행중 + 준공** 사업장 | 시기를 3분류해 배지로 표시 — `1년 이내 분양개시` / `분양 진행중` / `준공`. 입주예정월(`MVN_PREARNGE_YM`)이 지났으면 준공으로 본다 |
| **Q8/A8 — 1년 이내 분양개시 사업장이 있으면 그것을 우선** | [규정대로 자동선택] 이 1년 이내 분양개시 사업장이 있으면 **그것만** 고른다 |
| **Q9/A9 — 1년 이내가 없으면 분양가와 거래시세를 우선순위 없이 전부 적용해 평균** | 분양 진행중·준공을 구분 없이 후보에 둔다(우선순위를 두지 않는다) |

### ③ 유사도 — 4개 중 2개 이상 일치

| 항목 | 구분 | 원천 |
|---|---|---|
| 가. 주택유형 | 아파트 / 주상복합 / 기타 | 청약홈 구분에서 자동. 주상복합은 청약홈이 가리지 않아 본건만 수기 |
| 나. 단지규모 | 500세대 미만 / 500~999 / 1,000 이상 | `TOT_SUPLY_HSHLDCO` 로 **자동** |
| 다. 시공능력평가순위 | 50위 이내 / 51~100 / 101~200 / 201~300 / 300위 밖 | **이미 적재해 둔 대한건설협회 공시 명부로 자동 조회**. 컨소시엄("(주)태영건설,(주)동원개발,…")은 첫 시공사를 대표로 본다 |
| 라. 택지유형 | 민간택지 / 공공택지 / 신도시 / 기타 | **원천에 없다.** 본건만 입력받고 **상대는 「미상」** 으로 둬 판정에서 뺀다 — 추정해서 일치시키면 유사도가 부풀려진다 |

> 다목 단서(모회사가 책임준공 약정하고 모회사 브랜드 사용 시 모회사 시공순위 적용)는
> 자동 판정 대상이 아니다 — 약정 여부를 공개 원천이 모른다. 본건 시공순위는 수기로 고를 수 있다.

**우선순위** — 3개 이상 일치가 있으면 2개 일치보다 우선, 5년 이내 분양개시 우선.
단 심사 합리성을 위해 필요하면 2개 일치도 포함할 수 있다.
→ [규정대로 자동선택] 은 **3개 이상이 있으면 그것만** 고른다. 필요하면 실무자가 체크로 더한다.

## 2. 제16조 (예정분양가의 적정성분석)

| 조항 | 구현 |
|---|---|
| ①1가 — 평균가격 산출 | 고른 비교사업장들의 **산술평균**. 평가표 검산으로 확인: (6,435,829 + 5,548,625) ÷ 2 = 5,992,227 |
| ①2 가목 — 예정분양가가 **낮으면** 예정분양가 적용 | 적정분양가 판정 박스에 그대로 표기 |
| ①2 나목 — **높으면** 평균가격 적용 (사전협의 필요) | 같은 박스에 표기 |
| ②  — 인접한 사업장을 **우선** 적용 | 표를 거리순으로 정렬 |
| ④  — 적정분양가의 **±10% 이내**면 예정분양가를 적정한 것으로 인정 가능 | 110% 이내면 "인정할 수 있음" 으로 표기 |
| **Q10/A10 — 적정분양가의 90%보다 낮으면 적정한 것으로 간주** | 90% 미만이면 그 취지를 한 줄 더 적는다 |
| ⑥  — **미분양관리지역**이면 예정분양가가 적정분양가의 **105% 이내** | 체크박스로 켜면 105% 충족/초과를 판정 |
| ③ 분양가상한제 · ⑤ 고분양가 관리지역 · ⑦ 지역주택조합 | **자동 판정하지 않는다.** 관할관청 심의·고분양가 심사 상한·조합 공급비율은 공개 원천으로 알 수 없다 |

> **제16조의2(기분양사업장)** 은 분양보증이 이미 발급된 사업장에 쓰는 별도 절차라
> 이 탭의 범위 밖이다. ③항("2개 이상 사업장을 조사하여 평균") 은 실무 관행으로 참고만 했다.
> **제16조의3(임대조건율)** 은 주택임대사업 전용이라 범위 밖이다.

## 3. 분양가경쟁력 배점표

`config/scoring.json` 의 `분양가경쟁력` (scope `matrix`).

```
분양가격지수 = 본건 ㎡당 분양가 ÷ 비교사업장 평균 ㎡당 가격 × 100
행 = 분양가격지수 · 열 = 분양가격지수 제외 항목 점수(A)

                 43미만  43~67미만  67이상
  95미만            12       15       15
  95~100미만         9       12       15
  100~105미만        6        9       12
  105~110미만        3        6        9
  110이상            3        3        6

15 매우양호 · 12 양호 · 9 보통 · 6 열악 · 3 매우열악
```

**골든 검산** — A=56, 지수 100.96 → **9점 보통**. 평가표 캡쳐와 일치.

제외 항목 점수(A)는 다른 평가항목들의 합계라 이 앱이 계산하지 않는다 — 내부망 평가표에서 가져와 입력한다.
입력 전에는 점수를 매기지 않고 "제외 항목 점수(A)를 입력하세요" 로 둔다.

## 4. 반영하지 않은 것 (그리고 그 이유)

| 항목 | 이유 |
|---|---|
| 상대 단지의 **경계** 거리 | 공개 원천에 단지 경계 폴리곤이 없다. 대표지번 1점으로 재고 그 사실을 화면에 적었다 |
| **택지유형** 자동 판정 | 청약홈이 주지 않는다. 추정하면 유사도가 부풀려진다 |
| **주상복합** 구분 | 청약홈은 APT/오피스텔 계열만 가른다 |
| **준공 단지의 거래시세** | 평가표의 비교사업장은 준공 단지의 **주택시세(매매가)** 를 썼다. 우리는 **분양가**만 있다. 시세는 KB·부동산테크 등 별도 원천이라 이 탭의 숫자와 다를 수 있다 — 표에 시기 배지를 달아 구분한다 |
| 제16조 ③⑤⑦ | 관할관청 심의·고분양가 심사 상한·조합 공급비율은 공개 원천 밖 |
