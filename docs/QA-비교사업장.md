# 품질확인서 — 비교사업장 탭

- 일자 : 2026-09-14
- 요구 : ① 반경 1/2/3km 설정 → 지도에 반경 + 반경내 아파트 리스트업
        ② 분양가를 전용면적 기준 ㎡당 평균으로 표시
        ③ 여러 단지 선택 → 분양가 산술평균 실시간 산출
        ④ 선택 단지의 주소·이름·면적별 세대수를 별도 그리드로 (공공데이터 API)

## 1. 분석 — 분양가를 주는 원천이 있는가

| 후보 | 판정 |
|---|---|
| 국토부 아파트 실거래 | **분양가 아님** — 이미 팔린 값 |
| KB 시세 | **분양가 아님** — 기축 아파트 시세 |
| **한국부동산원 청약홈 분양정보** (공공데이터포털) | **채택** — 주택형별 분양가를 준다 |

키는 이미 있는 `DATA_GO_KR_KEY` 를 쓴다. 다만 포털 키는 **API 마다 따로 활용신청**이 필요하므로
"키가 있다" 와 "이 API 가 된다" 는 다른 이야기다 → 탐색 창구 `/api/applyhome` 을 먼저 배포해 확인했다.

**실측 결과 (2026-09-14, 둘 다 현재 키로 열림)**

```
분양정보  전국 2,875건 · 경기 913건 · perPage 1000 수용
주택형별  HOUSE_TY "084.7459A"      → 전용면적 84.7459㎡ + 타입기호
          SUPLY_AR "110.3043"      → 공급면적 (전용 아님)
          LTTOT_TOP_AMOUNT "89800" → 8억 9,800만원 (만원 단위)
          SPSPLY 16 + SUPLY 11     → 27세대
```

> **함정 — `SUPLY_AR` 을 전용면적으로 쓰면 단가가 25% 낮게 나온다.**
> 이름이 "공급면적"이 아니라 "SUPLY_AR" 이라 전용으로 읽기 쉽다.
> 전용률 76.8%(84.75/110.30)로 교차확인해 `HOUSE_TY` 가 전용임을 확정했다.

**또 하나 — 청약홈도 행정구역이 옛 체계다.** 광주 36건 / 전남 24건이 따로 잡힌다(실측).
KOSIS 와 같은 함정이라 `noticeSido()` 로 시군구를 봐서 가른다.

## 2. 설계

- **2단 필터로 지오코딩을 줄인다.** 시도 공고를 전부 지오코딩하면 800건이라 느리고 쿼터도 아깝다.
  → 시군구 중심좌표로 1차(반경+25km) → 남은 것만 지번 조회.
  실측 832건 → 326건 → 반경 판정.
- **재공고를 묶는다.** 원공고·조합원취소분·잔여세대가 각각 올라오는데 표기가 다르다.
  공백 지운 단지명 + 읍면동으로 묶고 최신 공고만 남긴다.
- **단지 대표단가는 두 가지를 다 낸다.** 세대수 가중평균(분양수입에 가깝다)과 주택형 단순평균.
  실무 관행이 갈리므로 **고르게 하고 어느 쪽을 썼는지 화면·엑셀에 같이 적는다.**
  단지끼리는 요구대로 **산술평균**을 쓴다.
- 거리·반경은 다른 시트와 같은 규칙 — 경계 기준으로 그릴 때만 경계 최단거리로 잰다
  (그린 선이 곧 판정선).

## 6. 한계 · 남은 것

- **분양 이력이 있는 단지만 나온다.** 청약홈에 공고가 올라온 분양 단지가 원천이므로
  기축 아파트나 공고 이전 단지는 대상이 아니다. (비교사업장 = 분양가 비교이므로 의도한 범위)
- **분양최고금액 기준이다.** 층·향별 차등의 최고가라 실제 평균 분양가보다 소폭 높을 수 있다.
  청약홈이 공개하는 값이 이것뿐이다.
- 공고일이 오래된 단지(2022년 등)도 반경 안에 있으면 표에 남는다 — **공고일을 표에 같이 적어**
  실무자가 시점을 보고 고르게 했다. 시점 필터가 필요하면 `/api/apts&from=YYYY-MM-DD` 가 이미 있다.
- 지도 렌더는 배포본에서만 확인 가능(로컬은 카카오 JS 키 도메인 제한).

# 보완 (2026-09-15) — 임대·오피스텔 처리

사용자 지적 : *"임대아파트라 그럴 수 있지 않을까"*

## 확인한 것

### ① 임대 필터가 실제로 무엇을 버리고 있었나

경기 공고 913건 = 분양주택 838 · 분양전환 가능임대 33 · 분양전환 불가임대 42.
버려진 75건 중 **경기도 광주시 건은 하나도 없었다** — 골든 사업장의 1km 0건은 임대 때문이 아니다.

다만 **조회 단계에서 조용히 버리는 구조가 문제였다.** 반경 안에 임대단지가 있어도
화면이 그 사실을 말하지 못한다. → 이제 거리를 재고 반경 안의 임대를 건수·이름으로 남긴다
(의료시설에서 의원급을 `excludedClinics` 로 남긴 것과 같은 방식).

### ② 진짜 구멍 — 오피스텔·도시형생활주택·민간임대는 다른 API 였다

```
getUrbtyOfctlLttotPblancDetail   전국 619건
  오피스텔 442 · 도시형생활주택 94 · 민간임대 80 · 생활형숙박시설 3
```

APT 분양정보만 보고 있어 **통째로 안 보였다.** 실측 :

| 사업지 | 반경 | 결과 |
|---|---|---|
| 서울 관악구 신림동 | 2km | 8건 중 **5건이 오피스텔·도시형** (아파트는 3건뿐) |
| 경기 광주시 탄벌동 | 3km | 해링턴 스퀘어 리버파크(오피스텔) 1건 추가 |
| 경기 용인시 삼가동 | 3km | 힐스테이트 용인포레(기업형민간임대) 1건 추가 |

### ③ 민간임대 금액은 분양가가 아니다 — 섞으면 평균이 반토막 난다

| 단지 | 전용 | 금액 | 원/㎡ |
|---|---|---|---|
| 힐스테이트 용인포레(기업형민간임대) | 59.96㎡ | 1억 3,500만 | **2,080,944** |
| 안성 공도 센트럴카운티(민간임대) | 84.93㎡ | 2억 6,500만 | **3,120,323** |
| 신대방역 더하이브퍼스트(도시형·분양) | 59.95㎡ | 8억 6,700만 | 14,723,136 |

용인 신축 아파트가 평당 744만원일 수 없다 — **임대보증금**이다.
→ 값은 보여주되 **체크박스를 막아** 분양가 평균에 못 들어가게 했다.

## 반영

- 두 원천을 같이 조회하고 **종류를 끝까지 들고 다닌다**.
- **종류 칩**(아파트 · 민간임대 · 오피스텔 · 도시형생활주택)으로 켜고 끈다. 기본은 아파트만.
  종류를 끄면 그 종류로 고른 것도 평균에서 뺀다.
- 재공고 묶음키가 괄호 **안 글자**를 안 지워 "○○(조합원 취소분)" 이 원공고와 따로 앉던 것도 고쳤다.
