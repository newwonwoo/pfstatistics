# 품질확인서 — 초기예상분양률 (평가표의 결론)

- 대상 : 금융심사처 실무 가이드북 「초기예상분양률」 급간표 (2026-09-16 수령)
- 커밋 : `fa4c160`
- 검증자 : 자가검증 (골든 대조 + 급간 경계 전수)

## 1. 무엇을 만들었나

이 앱은 항목별 점수만 내고 **결론을 안 내고 있었다.** 사용자 지적("초기분양률은 산정하는거잖아")으로
평가표 전체의 목적이 드러났다 — 실제 평가표 파일명이 「3. (탄벌A지구) **초기분양률 산정근거**_최종.xlsx」 이고,
가이드북 캡쳐 머리글도 「분양률 산정을 위한 평가기준」 이다.

```
각 시트의 항목 점수  →  종합평가 점수  →  급간표  →  초기예상분양률(%)
```

`초기예상분양률` 탭을 만들어 이 흐름을 화면과 엑셀에 올렸다.

## 2. 요구사항 적합 여부

| # | 요구사항 | 결과 |
|---|---|---|
| 1 | 총점 → 분양률 급간표 적용 | **적합** — 골든 일치 |
| 2 | 오피스텔·도시형 별도 급간 | **적합** — 칩으로 전환 |
| 3 | 100세대 미만 60% 상한 | **적합** — 깎으면 경고로 남김 |
| 4 | 종합평가 점수 산출 | **적합** — A + 분양가경쟁력, 두 탭이 같은 함수 사용 |
| 5 | A 를 추정하지 않음 | **적합** — 입력받고, 이 앱이 낸 점수는 대조표로만 |
| 6 | 두 "초기분양률" 구분 | **적합** — 화면·엑셀·config 에 명시 |

## 3. 골든 대조

| 항목 | 값 | 출처 |
|---|---|---|
| 분양가격지수 제외 항목 점수 (A) | 56 | 실제 평가표 「분양가경쟁력」 시트 |
| 분양가경쟁력 | 9 | 분양가격지수 100.96 · A 56 → 행렬 판정 (기검증) |
| **종합평가 점수** | **65** | 56 + 9 |
| **초기예상분양률** | **70%** | 65~75점 미만 → 70% |

산출 결과가 `65점 → 65 ~ 75점 미만 → 70%` 로 정확히 재현된다.

## 4. 급간 경계 전수 (주택 / 오피스텔·도시형)

```
100점 → 100% /  90%      95점 → 100% /  90%      94점 →  90% /  80%
 85점 →  90% /  80%      84점 →  80% /  70%      75점 →  80% /  70%
 74점 →  70% /  60%      65점 →  70% /  60%   ← 골든
 64점 →  60% /  50%      55점 →  60% /  50%      54점 →  50% /  40%
 45점 →  50% /  40%      44점 →  40% /  30%      35점 →  40% /  30%
 34점 →  30% /  20%       0점 →  30% /  20%
```
경계가 "이상/미만" 원문대로 붙는다. 오피스텔·도시형은 전 구간에서 정확히 10%p 낮다.

## 5. 100세대 미만 상한

```
95점 ·  80세대 → 100% 에서 깎아 60%      65점 ·  80세대 →  70% 에서 깎아 60%
55점 ·  80세대 →  60%  (원래 60% 라 변화 없음)
95점 · 100세대 → 100%  (100세대는 "미만" 이 아니다)
95점 · 세대수 미입력 → 100%  (상한 미적용)
```
깎인 경우 화면에 `100% → 60% 로 상한 적용` 과 근거 문장을 남긴다.
**조용히 깎지 않는다** — 왜 낮은지 설명이 없으면 실무자가 계산 착오로 의심한다.

## 6. A 를 계산하지 않는 이유

A 안에는 이 앱이 자동수집할 수 없는 항목이 들어 있다.

| 항목 | 배점 | 이 앱 |
|---|---|---|
| 교통환경 · 주거편의 · 교육환경 · 브랜드경쟁력 · 주택담보대출금리 | 각 5 | **자동 산출** |
| 규모 및 배치 · 평형구성 | 각 5 | 수기입력 시트 — 범위 밖 |
| 인근아파트 초기 분양률 | 10 | 옆 단지의 실제 분양률 조사 — 공공 원천 없음 |
| 지역미분양 · 지역수요 · 지역경쟁력 · 소비심리지수 | 미수령 | 수치는 수집, 구간표 일부 미수령 |

그래서 A 는 **내부망 평가표 값을 입력받고**, 이 앱이 낸 점수는 그 아래 **대조표**로만 보여준다.
추정해서 A 를 만들면 분양률이 통째로 틀린다.

## 7. 설계상 주의

- **분양가경쟁력 산식은 `src/lib/compare.js` 한 곳**에만 둔다. 비교사업장 탭과 이 탭이
  같은 함수를 쓰지 않으면 한쪽만 고쳐져 두 화면의 숫자가 조용히 갈린다.
- 종합평가 점수는 A 와 분양가경쟁력이 **둘 다** 있어야 낸다. 한쪽만으로 부분 합계를
  보여주면 그것이 총점으로 읽힌다.

## 8. 결론

요구사항에 **적합**하다. 골든 1건(65점 → 70%) 일치, 급간 경계 16개 + 상한 5건 전수 확인.
추정으로 채운 값은 없다.
