## 한눈에 — 무엇이 같고 무엇이 다른가

| | **A. 분양가경쟁력(15)** | **C. 분양보증 적정분양가** | **B. 인근아파트 초기분양률(10)** |
|---|---|---|---|
| ① 거리 | 2km (수도권·광역시 1km) | 같음 | 같음 |
| ② 시기 | 최근 1년 이내 분양개시 → 없으면 **분양 진행중 + 준공** | 같음 | 최근 1년 이내 분양개시 → 없으면 **분양 진행중만** (준공 ✗) |
| ③ | **유사도** 가~라 중 **2개 이상** 일치 | 같음 | **주택유형 일치** (요건) |
| 우선 | 3개 이상 일치를 2개 일치보다 우선 | 3개 이상 우선 **+ 5년 이내 분양개시 우선** | 여럿이면 가~라가 **가장 많이** 일치하는 곳 |
| 단서 | 심사 합리성을 위해 필요시 우선순위 없이 2개 일치도 포함 | 같음 | — |
| 여럿일 때 | 평균가격 | 평균가격 | 가장 많이 일치하는 곳이 여럿이면 **평균값** |
| 없을 때 (비고1) | **매 1km 확장**해 재조사 · 5km 안에도 없으면 10년 경과 산입 본·지사 협의 | 같음 | **최하위 배점** (확장 없음) |
| 제외 (비고2) | 공공분양 · 분양개시 후 10년 경과 등 평균가격 왜곡 | 같음 | (규정 없음) |

가~라 네 항목은 **세 기준 모두 같다**:
가. 주택유형 아파트 / 주상복합 / 기타 · 나. 단지규모 500세대 미만 / 500~999 / 1,000 이상 ·
다. 시공능력평가순위 50위 이내 / 51~100 / 101~200 / 201~300 / 300위 밖
(모회사가 책임준공 약정하고 모회사 브랜드를 쓰면 모회사 순위 적용 가능) · 라. 택지유형 민간택지 / 공공택지 / 신도시 / 기타

**A 와 C 는 한 줄만 다르다** — C 의 ③ 단서에 「및 **5년 이내 분양 개시 사업장으로 우선 선정**」 이 더 붙어 있다.
**B 는 요건 자체가 다르다** — 유사도는 요건이 아니라 순위를 매기는 잣대이고, 주택유형 일치가 요건이다.

## 이 앱의 설계

- **비교사업장 탭** — 한 목록에서 두 기준을 쓴다.
  - [규정대로 자동선택] 은 **A** 로 고른다(분양가경쟁력 점수가 쓰는 목록).
  - 적정분양가 표의 ① 평균가격은 고른 목록에 **C 의 한 줄(5년 이내 우선)** 을 더 걸어 낸다.
    5년 이내가 하나라도 섞여 있으면 5년 넘은 곳을 빼고, 뺀 단지 이름을 그 줄에 적는다(엑셀도 같다).
    대부분은 두 목록이 같다 — 1년 이내 분양개시 단지는 모두 5년 이내이기 때문이다.
- **초기예상분양률 탭의 인근아파트 초기분양률** — **B** 로 따로 찾는다(비교사업장 목록을 쓰지 않는다).
  - 거리는 규정으로 고정(반경 칩을 없앴다).
  - 주택유형 일치 → 시기 → 가~라 일치 개수 순. [규정대로 선정] 이 **가장 많이 일치하는 곳**을 고른다.
  - 가~라 네 항목은 **비교사업장 탭 [본건 제원] 과 같은 값**이다 — 이 탭에서 고쳐도 그쪽이 같이 바뀐다.

## 판단이 필요했던 곳 (원문이 정하지 않은 것)

| 자리 | 이 앱의 해석 | 근거 |
|---|---|---|
| C 에서 「3개 이상 우선」 과 「5년 이내 우선」 의 **순서** | 3개 이상을 먼저, 5년 이내를 그다음에 건다 | 원문이 「3개 이상 … 우선 선정 **및** 5년 이내 … 우선 선정」 순으로 적었다. 반대로 해석하면 적정분양가 목록이 분양가경쟁력 목록 밖으로 나갈 수 있다 |
| B ③ 「주택유형이 일치」 에서 주상복합 | 청약홈은 주상복합을 가리지 않는다 — ③은 **아파트 계열**(아파트 분양보증 → 아파트, 오피스텔 분양보증 → 오피스텔·도시형)로 보고, 가목 일치는 본건 값으로 따로 센다 | 원천 한계 |
| 택지유형 (라) | 상대 단지는 **미상** — 일치로 세지 않는다 | 청약홈에 없다. 추정하면 유사도가 부풀려진다 |

## 남은 차이 (알고 쓰는 것)

- **Q9 의 준공 단지 「거래시세」** — 이 앱의 준공 단지 값은 청약홈 **분양가**다. 실거래가는 따로 받지만 **전용면적** 기준이라
  공급면적 단가와 그대로 섞을 수 없다(CLAUDE.md 「국토교통부 아파트 매매 실거래가」). 평가표의 비교사업장 평균이
  우리 값과 다른 이유가 이것이다(docs/규정-분양가적정성.md 5절).
- **B 의 옛 원문**(2026-09-16 수령)은 「인근」 이라고만 적고 유사도를 「위치·세대수·브랜드」 로 적었다.
  이번 선정 방법 원문이 더 구체적이라 그것을 따른다. 단서(수용·환지 사업지구 내 최초 분양 = 4점)는 옛 원문에만 있어 그대로 둔다.
