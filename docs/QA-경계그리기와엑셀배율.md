# 품질확인서 — 경계 그리기 동선 · 엑셀 증빙 배율

- 배포 : `43889db` (https://pfstatistics.vercel.app/)
- 표본 : 경기도 광주시 탄벌동 203-4 · 제일건설(주)
- 확인일 : 2026-09-17 · 헤드리스 브라우저로 배포본을 사람처럼 조작

## 1. 요구사항

| # | 사용자 요구 |
|---|---|
| 1 | 화면에서 한번 돌려보자 |
| 2 | 지도에 경계 그리는 게 애매하다 — UX 가 헷갈린다 |
| 3 | 엑셀 다운로드했을 때 지도 확대 배율을 확인 못 했다 |
| 4 | 시설물은 배지 말고 동그라미 표시를 해주는 것도 좋아 보인다 |

## 2. 검증 — 실제 조작

```
주소확정 → 통계 7/7 수집(골든 검증 배지 정상)
        → [반경시설 수집] → [사업지 경계 기준] → 지도에 4점 클릭
        → [이 경계로 반경시설 수집] → 시설 3/3 → 엑셀 다운로드
```
전 구간이 화면에서 돌았다. 골든값 재현 : 미분양 93호 · 세대수 178,187 · 보급률 99.4% · 소비심리 125.1.

## 3. 찾은 결함과 수정

### 3.1 안내문이 가리키는 버튼이 화면에 없었다 (요구2 의 정체)

경계 기준을 고르면 배너가 **"[이 경계로 수집] 을 누르세요"** 라고 적는데,
**그 이름의 버튼은 어디에도 없었다.** 실제로는 **674px 위** 단계 줄의
[반경시설 수집 (3종)] 을 다시 눌러야 했다. 지도가 닫혀서가 아니라 **끝내는 방법이 안 보였던** 것이다.

→ 경계 기준을 고른 **그 순간에만** 지도 발치에 `[이 경계로 반경시설 수집]` 버튼을 둔다.
3점 미만이면 못 누르고 사유를 버튼 글자로 보여준다(`경계를 N점 더 찍으세요`).
수집이 끝나면 사라지므로 **수집 버튼이 두 군데 서 있지 않는다**.

### 3.2 3배로 찍기로 해놓고 2배로 찍히고 있었다 (요구3)

| | 원본 픽셀 | 배치 | 확대여유 |
|---|---|---|---|
| 고치기 전 | 2096 × 1280 | 1240px | **1.69배** |
| 고친 뒤 | 3324 × 1920 | 1240px | **2.68배** |

`composeMap` 기본값을 3 으로 올렸는데 부르는 쪽 `captureMap({ pixelRatio = 2 })` 가 덮고 있었다.

### 3.3 그 대가로 파일이 47MB 가 됐다

타일은 연속톤 사진이라 PNG 가 최악이다. 지도만 JPEG(0.92)로 바꿨다.

| | 파일 크기 | 확대여유 |
|---|---|---|
| 3배 PNG | 47 MB | 2.68배 |
| **3배 JPEG** | **8 MB** | **2.68배** |

표·글자 증빙(카드)은 PNG 를 유지한다(3144 × 651 · 2.54배).

### 3.4 이름표 끄기 (요구4)

마커가 있는 지도마다 `[이름표 끄기]` 를 달았다(실측 6곳). 끄면 **번호 동그라미만** 남는다.
기본은 켜 둔다 — 증빙에는 이름이 있어야 한다. **화면에서 끄면 캡쳐도 같이 꺼진다.**

## 4. 한계

- 지도 타일 자체는 1배다. 3배로 찍어도 **타일 그림**은 확대의 한계가 있다 —
  선명해지는 것은 캔버스에 직접 그리는 핀·라벨·반경원·경계선이다.
- JPEG 는 손실 압축이다. 품질 0.92 에서 글자는 그대로지만 타일의 미세한 색 경계는 약간 뭉갠다.
